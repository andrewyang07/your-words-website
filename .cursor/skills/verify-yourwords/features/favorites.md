# Favorites (收藏)

## Sub-features
- Star a verse from search results/cards (`加入我的收藏` ↔ `取消我的收藏`).
- Persisted in localStorage `favorites-storage` (`{state:{favorites:[ids]}}`, id = `<简体书名>-<章>-<节>`).
- Favorites feed the `/memorize` picker.

## How to get to it (user POV)
`/search?q=神爱世人` → click the star on a result → open 深度背诵 (`/memorize`).

## Driving it with Playwright
`drive.sh favorites`: clicks the first `加入我的收藏`, asserts the button flips, reads `favorites-storage`, then asserts `/memorize` lists `<书名> <章>:<节>`.

## Gotchas
- Search relies on the pagefind index generated by `prebuild`; under `--dev` without a prior build, search may return nothing.
- Search ranking decides which verse is first — assert on whatever id was stored, not a fixed verse.
