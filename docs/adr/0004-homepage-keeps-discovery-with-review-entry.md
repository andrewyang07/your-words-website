# Homepage Keeps Discovery With Review Entry

> Status: Amended. The homepage keeps discovery and reading, but its entry now opens `/memorize`; shared Deep Memorization links carry one verse and no personal progress. See `docs/prd-daily-review.md`.

The homepage keeps the existing reading and discovery workflows: masking controls, read mode, book/chapter browsing, search, sharing, help, Side Menu, favorites, rankings, and full-chapter viewing. Daily Review is added as a lightweight Homepage Review Entry near the top, while `/discover` may remain as a focused discovery route but must not replace the homepage's established workflows. Shared links carry verse membership only, not progress or ratings; Shared Review can still create local progress before the user explicitly saves those verses.
